# Dashboard de Gestión para Restaurantes

Este proyecto es un prototipo estático (UI/UX) de un dashboard para un sistema de gestión de restaurantes, diseñado para optimizar el uso de ingredientes y reducir el desperdicio de alimentos mediante análisis y predicción de consumo.

## Características

- **Resumen General**: KPIs con platos servidos, desperdicio estimado, productos en stock crítico y ganancia neta.
- **Gestión de Mesas**: Interfaz visual para ver el estado de las mesas, historial de pedidos y costos.
- **Chatbot Predictivo**: Asistente virtual para sugerir platos a preparar y alertar sobre productos por agotarse.
- **Inventario/Almacén**: Registro detallado de productos con visualización de stock y alertas.
- **Análisis Económico**: Métricas de rentabilidad y relación entre platos vendidos y productos usados.

## Tecnologías

- **Frontend**: Next.js + TailwindCSS
- **Visualización de datos**: Chart.js
- **Iconos**: React Icons

## Instalación

```bash
# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev
```

## Notas

Este es un prototipo estático diseñado para mostrar la interfaz de usuario y experiencia de usuario (UI/UX). No tiene funcionalidad de backend implementada.
